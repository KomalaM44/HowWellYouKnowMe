# How Well Do You Know Ashika?

A static birthday party quiz app designed for streaming to a big TV.

## Features

- Add friends or teams before the game starts.
- Add custom questions, correct answers, and multiple-choice options.
- Reveal each answer on the TV.
- Tap friends who guessed correctly to award points.
- Show a live scoreboard and final winner screen.
- Saves players and questions in browser local storage.
- Runs as plain static files, so it works on GitHub Pages.

## Run Locally

Open `index.html` in a browser.

## GitHub Pages

Push these files to a GitHub repository, then enable GitHub Pages from the repository settings. Use the repository root as the Pages source.
